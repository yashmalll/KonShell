# KonShell

**Минималистичная оболочка рабочего стола для [niri](https://github.com/YaLTeR/niri) на [Quickshell](https://quickshell.org)**

Панель, док, лаунчер, уведомления, центр управления, экран блокировки и цвета под обои —
одной оболочкой, без waybar, mako, fuzzel и swaylock.

## Возможности

**Рабочий стол**
- **Панель** с зонами слева, по центру и справа — виджеты расставляются перетаскиванием в настройках: мини-карта рабочих столов niri, заголовок окна, трей (кнопкой со всплывающим окном; любой значок можно вынести на панель), раскладка, сеть/звук/батарея, уведомления, часы, дата, погода, плеер, скорость сети, монитор системы, кнопка заметки.
- **Панель под часами** — время, погода на 5 дней, календарь, плеер с перемоткой, быстрые заметки в Markdown, нагрузка системы и диски, сеть с внутренним и внешним IP. Колонки рядом, размер по содержимому; карточки и колонки настраиваются.
- **Док** с закреплёнными и запущенными приложениями, автоскрытием и меню окон; прижат к краю экрана с плавными закруглениями или плавающий — на выбор.
- **Лаунчер** с нечётким поиском и частыми приложениями выше.
- **Центр управления** — Wi-Fi, Bluetooth, звук и устройства, яркость, профили питания, «Не беспокоить», «Не засыпать».
- **Боковая панель** у края экрана (упритесь мышью в правый или левый край) — заметки в Markdown со списком, поиском, просмотром и правкой в отдельном окне, скриншот и запись экрана.
- **Уведомления** со всплывающими карточками, историей, действиями и режимом «Не беспокоить».
- **История буфера обмена** с поиском и картинками.
- **Запись экрана** — весь экран или область, со звуком, кодирует видеокарта.

**Система**
- **Экран блокировки** — пароль или PIN, блокировка по простою и перед сном.
- **Меню выключения** с обратным отсчётом, который можно отменить.
- **Polkit-агент** — окно ввода пароля администратора.
- **Индикаторы** громкости и яркости.

**Оформление**
- **Цвета под обои** (Material You через matugen) — и для оболочки, и для **GTK, Qt, kitty, niri, Firefox, Zed**.
- Тёмная и светлая тема, варианты палитры, прозрачность с размытием, плавные анимации (ровные 60 FPS).
- **Окно настроек** — 19 разделов с поиском.

## Требования

- **Arch Linux** или производный дистрибутив с `pacman`
- **niri** 26.04 или новее — оболочка рассчитана на него (рабочие столы, обзор, правила слоёв)
- **Quickshell** 0.3 или новее — ставится установщиком из официального репозитория

Все пакеты — из официальных репозиториев Arch, AUR не нужен.

## Установка

```sh
git clone https://github.com/yashmalll/KonShell.git ~/.local/share/konshell
cd ~/.local/share/konshell
./install.sh
```

Папку можно выбрать любую — установщик сделает на неё ссылку. Запускать лучше из сеанса niri: тогда оболочка сразу запустится.

<details>
<summary><b>Что делает установщик</b></summary>

1. **Пакеты.** Ставит недостающие обязательные (`quickshell matugen brightnessctl ffmpeg curl python libnotify xdg-utils`) и, после вопроса, дополнительные (`cliphist wl-clipboard wf-recorder slurp grim qt6ct adw-gtk-theme kimageformats python-pywalfox`).
2. **Quickshell.** Ссылка `~/.config/quickshell/konshell` → папка проекта; оболочка запускается командой `qs -c konshell`.
3. **niri.** Ссылка `~/.config/niri/konshell.kdl` → [`niri/konshell.kdl`](niri/konshell.kdl) (автозапуск, клавиши, обои) и строка `include "konshell.kdl"` в конце `config.kdl`. Автозапуск waybar, mako, swaybg и подобных комментируется — они дублировали бы оболочку. Перед первой правкой сохраняется копия `config.kdl.konshell-bak`; если конфиг после правки не проходит `niri validate`, изменения откатываются.
4. **Цвета приложений.** Подключает файлы цветов к kitty, GTK 3/4, niri, Zed и Qt (копии изменённых файлов — `*.konshell-bak`).
5. **Запуск** оболочки, если вы в сеансе niri.

Повторный запуск ничего не дублирует. Ключи: `--yes` — без вопросов, `--no-packages` — не трогать пакеты.

</details>

## Первые шаги

- **Обои** — положите картинки в `~/Pictures/Wallpapers` и выберите в «Настройки KonShell» → «Обои». Цвета оболочки и приложений подстроятся сами.
- **Настройки** — «Настройки KonShell» в лаунчере (`Mod+Space`), или значок шестерёнки в центре управления.
- **Погода** — укажите город в «Часы и календарь» → «Погода».
- **PIN** экрана блокировки — «Блокировка» → «PIN». Пароль пользователя работает всегда.
- **Firefox** — поставьте расширение [Pywalfox](https://addons.mozilla.org/firefox/addon/pywalfox/), цвета подтянутся.

## Клавиши

| Клавиши | Действие |
|---|---|
| `Mod+Space` | Лаунчер |
| `Mod+Alt+V` | История буфера обмена |
| `Mod+Alt+N` | Новая заметка |
| `Mod+Shift+E` | Выключение, перезагрузка, выход |
| `Super+Alt+L` | Заблокировать экран |
| Клавиши громкости и яркости | С индикатором оболочки |

Клавиши заданы в [`niri/konshell.kdl`](niri/konshell.kdl) и перекрывают такие же в `config.kdl`. Чтобы переназначить, добавьте свою привязку в `config.kdl` **после** строки `include "konshell.kdl"`.

Всё остальное доступно мышью: клик по часам — панель с календарём и заметками, по значкам сети и звука — центр управления, по колокольчику — история уведомлений.

## Настройка

Почти всё меняется в окне «Настройки KonShell» и применяется сразу. Настройки хранятся в `~/.config/konshell/settings.json`, его можно править и руками — оболочка перечитает файл на лету.

Оболочкой можно управлять из терминала и скриптов:

```sh
qs -c konshell ipc show                          # все команды
qs -c konshell ipc call launcher toggle
qs -c konshell ipc call wallpaper next
qs -c konshell ipc call theme setMode light
qs -c konshell ipc call recorder toggle          # запись экрана
qs -c konshell ipc call session request reboot   # перезагрузка с отсчётом
```

## Обновление

```sh
~/.local/share/konshell/install.sh --update                 # git pull + установка новой версией и перезапуск
~/.local/share/konshell/install.sh --update --no-packages   # то же, не трогая пакеты
```

Обновление — только fast-forward: если в репозитории есть ваши незакоммиченные правки или ветка разошлась с удалённой, скрипт остановится и ничего не тронет.

## Удаление

```sh
./install.sh --uninstall           # настройки остаются в ~/.config/konshell
./install.sh --uninstall --purge   # вместе с настройками, PIN и кэшем
```

Установщик уберёт ссылки, строку `include`, подключения цветов и вернёт закомментированный автозапуск. Пакеты не удаляются. Перезайдите в сеанс niri.

## Если что-то не так

- **Оболочка не появилась** — запустите `qs -c konshell` в терминале: ошибки будут в выводе.
- **niri ругается на конфиг** — `niri validate`; исходная копия — `~/.config/niri/config.kdl.konshell-bak`.
- **Экран заблокирован, а оболочка упала** — niri оставит экран заблокированным, это защита. Перейдите в консоль (`Ctrl+Alt+F3`), войдите и выполните `pkill -x qs; WAYLAND_DISPLAY=wayland-1 qs -c konshell &`, вернитесь (`Ctrl+Alt+F1` или `F7`) и разблокируйте.
- **Значки приложений вместо цвета — квадраты** — поставьте тему значков с symbolic-иконками (`adwaita-icon-theme`).
- **Прежние панель или уведомления** — перезайдите в сеанс niri, установщик отключил их автозапуск.

## Устройство

```
shell.qml          точка входа
config/            Theme (цвета, шрифты, отступы), Settings, реестр настроек
services/          данные: niri, звук, сеть, батарея, уведомления, погода, буфер обмена…
modules/           панель, док, лаунчер, центр управления, блокировка, настройки…
widgets/           общие элементы интерфейса
templates/         шаблоны цветов для GTK, Qt, kitty, niri, Firefox, Zed
niri/konshell.kdl  автозапуск, клавиши и правила для niri
scripts/           палитра из обоев, миниатюры, подключение цветов к приложениям
install.sh         установка и удаление
```

Подробно — модули, сервисы, IPC, решения и замеры производительности — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
